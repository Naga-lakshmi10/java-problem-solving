## 💻 How to Run the Programs

1. Clone the repository:

   ```bash
   git clone https://github.com/Naga-lakshmi10/java-problem-solving.git
   ```

2. Open the project in IntelliJ IDEA or your preferred Java IDE.

3. Ensure that JDK 21 or a compatible JDK is configured.

4. Navigate to the Java file you want to execute.

5. Run the program using the IDE or compile and execute it from the terminal.

   ```bash
   javac HelloWorld.java
   java HelloWorld
   ```
